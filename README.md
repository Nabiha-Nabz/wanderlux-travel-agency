# WanderLux Travel Agency

WanderLux is a responsive, multi-page travel agency website with destination discovery, service information, a trip-cost calculator, appointment booking, and contact experiences.

> **Client project:** This website was designed and developed for a client. It is published here as a portfolio and project-delivery reference.

## Features

- Responsive luxury travel landing page
- Featured destination cards, including the Maldives
- Travel services and company information pages
- Interactive trip-cost calculator
- Appointment and contact forms with client-side validation
- Shared styling and navigation across all pages

## Run locally

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

For the best local-development experience, serve the folder with any static web server, for example VS Code Live Server.

## Pages

- `index.html` — home and featured destinations
- `services.html` — destinations and services
- `calculator.html` — trip-cost calculator
- `appointment.html` — consultation booking
- `about.html` — company story and team
- `contact.html` — contact form and details

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
